# Desafio Integrador - Sistema de Consulta de Benefícios

Atividade desenvolvida em Java para a disciplina de Lógica de Programação e Algoritmos.

## Sobre a atividade

O programa realiza uma consulta de benefícios para colaboradores a partir das seguintes informações:

- Nome do colaborador;
- Idade;
- Salário;
- Tempo de empresa;
- Quantidade de filhos;
- Modalidade de trabalho;
- Utilização de veículo próprio.

Com base nos dados informados, o sistema verifica o direito aos seguintes benefícios:

- Vale-alimentação;
- Auxílio-creche;
- Plano de saúde;
- Auxílio home office;
- Auxílio combustível;
- Participação na PLR;
- Bolsa de estudos.

## Tecnologia utilizada
